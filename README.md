# Word Guessing Game (Python)

A CLI-based word guessing game built with Python. Inspired by the Codédex project tutorial.

## How to Play
1. The game randomly selects a secret word from a word bank.
2. Guess hidden letters one by one before running out of attempts.
3. If you guess all letters before running out of attempts, you win!
